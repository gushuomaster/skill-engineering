# Quality Gate Contract

The Quality Gate is the single engineering release boundary. It evaluates normalized deterministic evidence and verifies that Codex explicitly confirmed the semantic goal for the exact artifact digest. Deterministic checks alone cannot produce final PASS. Provider or heuristic output cannot satisfy semantic confirmation. Any ordinary required check with `FAIL`, `ERROR`, `SKIP`, or `NOT_EXECUTED` blocks release; rule detector signals remain advisory. Audit Only is never publish-authorized, failures never authorize publication, and a passing candidate without an explicit publish request remains staged with `publish_authorized=false`. Publication rechecks both the source baseline digest and the confirmed candidate digest before any replacement.
