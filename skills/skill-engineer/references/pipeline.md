# Pipeline Contract

Codex controls the workflow. It interprets the request, chooses the mode, performs RCA and classification, selects mechanisms, authors the candidate, resolves rule signals, and confirms semantic completion. The orchestrator validates those explicit inputs and performs deterministic staging, inventory, diff, checks, evidence collection, and Gate evaluation.

Create uses a complete Codex-authored candidate in an independent directory. Modify and Fix use a candidate separate from the source and the Engine stages it again before validation. Audit Only remains read-only. Audit + Optimize audits first and stages only an authorized candidate. Modification authorization permits staging; it does not authorize publication. Without an explicit publish request, a valid candidate can pass the Gate while `publish_authorized` remains false. Gate readiness and atomic publication are separate operations.

For CLI execution, pass real behavior and regression commands as JSON string arrays through `--behavior-command-json` and `--regression-command-json`. The CLI runs them with the staged artifact as the working directory and records the exact command, exit status, stdout, and stderr; absent required commands remain `NOT_EXECUTED` and cannot become PASS. `--publish` supplies the separate publication request, and the CLI calls `publish(outcome)` only after `run()` returns a Gate-ready result.
